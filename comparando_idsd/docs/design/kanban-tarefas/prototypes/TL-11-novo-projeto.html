Novo projeto

Visível apenas para a administração global

TL-11 — Novo projeto. Criar projeto é capacidade exclusiva da administração global: nenhum papel de projeto a possui, porque nenhum papel de projeto existe antes de o projeto existir. A criação nomeia a primeira administradora do projeto na mesma operação — sem isso o projeto nasceria sem ninguém dentro dele e sem ninguém que pudesse conceder a primeira participação. Quem cria não vira participante: o alcance global já lhe dá acesso, e virar participante confundiria escopo com participação. O projeto nasce sem fluxo, e o estado de sucesso abaixo existe para que o segundo passo obrigatório não fique só na cabeça de quem fez o primeiro.

É como o projeto aparece na lista, no board e no andamento.

Opcional.

Obrigatória. Ela recebe o papel de administradora do projeto na mesma operação e passa a ser quem configura o fluxo e concede as demais participações. Só aparecem aqui contas que já entraram no sistema ao menos uma vez — é a primeira entrada que cria a conta a partir do provedor corporativo.

O projeto não aparecerá em “Meus projetos” para você Você o alcança pela administração global, e não por participação. A lista marca esse acesso como alcance global justamente para que ele não se confunda com estar dentro do projeto.

Escolha quem será a administradora do projeto. Sem ela o projeto nasceria sem ninguém dentro, e ninguém poderia conceder a primeira participação.

A lista só oferece contas que já existem, mas a recusa não depende dela: o servidor rejeita a criação com essa mesma razão se a pessoa não existir no momento da gravação — quem nunca entrou no sistema não tem conta a nomear (RNF-004).

Estado — enviando

O projeto e a primeira participação são gravados juntos. Se a segunda falhar, a primeira não fica: um projeto sem ninguém dentro é inalcançável.
